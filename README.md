
# Smart Hotel Booking Cancellation Prediction and Analytics

## Project Overview
An end-to-end Machine Learning project to predict hotel booking cancellations and analyze booking patterns.

## Problem Statement
Hotel booking cancellations can affect revenue, room availability, and operational planning. This project aims to identify booking characteristics associated with cancellations and build a classification model to predict cancellation risk.

## Dataset
- Name: Hotel Booking Demand
- Source: https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand
- Records: 119,390
- Columns: 32
- Target: is_canceled

Download the dataset from Kaggle and save it as `data/hotel_bookings.csv`.
